# Combatant

Пет-проект: XCOM-подобная игра (менеджмент базы, потом тактика). Код пишется вручную. Цель — выучить и вспомнить C++ и довести игру до играбельного вида. ИИ в репозитории не автор кода: его использовали только для документации.

Подробности по коду и задумке базы — в каталоге `docs/`. Чеклисты — `docs/checklists/`.

## Стек

- **Язык:** C++26, расширения компилятора выключены
- **Сборка:** CMake 4.4.3
- **Каталоги:** `include/`, `src/`, `tests/`; `data/` зарезервирован под JSON, пока пустой или отсутствует
- **Платформа разработки:** Windows
- **Библиотека:** статическая цель `combatant`
- **Тесты:** свой тонкий харнесс (`tests/test_harness.hpp`), исполняемый `Combatant_tests`. Catch2 в CMake ещё не подключён

Планируется подключить:

- nlohmann/json — данные и сохранения
- Catch2 — вместо или поверх текущего харнесса
- spdlog — логи
- ImGui (docking) или raylib — интерфейс (выбор позже)

Логика игры не зависит от UI. Числа баланса в JSON — загрузчик ещё впереди. Карточки в коде — временный способ жить до загрузчика.
