# Combatant

Пет-проект: XCOM-подобная игра (менеджмент базы, потом тактика). Код пишется вручную. Цель — выучить и вспомнить C++ и довести игру до играбельного вида. ИИ в репозитории не автор кода: его использовали только для документации.

## Стек

- **Язык:** C++26, расширения компилятора выключены
- **Сборка:** CMake 4.4.3, каталоги `include/`, `src/`, `data/`, `tests/`
- **Платформа разработки:** Windows

Планируется подключить:

- nlohmann/json — данные и сохранения
- Catch2 — тесты
- spdlog — логи
- ImGui (docking) или raylib — интерфейс (выбор позже)

Логика игры не должна зависеть от UI. Данные предметов и баланса — в JSON, без хардкода чисел в коде (загрузчик ещё впереди).
